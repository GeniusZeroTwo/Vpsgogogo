# 🚀 VPS 网络全能优化脚本 (Vpsgogogo)

一个专为高延迟 VPS (如美国、欧洲、亚洲跨国线路) 设计的深度优化脚本。集成 BBRv3、TCP Fast Open、并发队列优化以及 Hysteria2 智能守护逻辑。

---

## ⚡ 一键执行命令 (推荐)

在你的 VPS 终端（Root 用户）直接粘贴以下命令：

```bash
curl -fsSL "https://raw.githubusercontent.com/GeniusZeroTwo/Vpsgogogo/main/optimize.sh" | sudo bash
```



#  通过 snap 安装
```bash
sudo snap install speedtest
```
# 运行测速
```bash
speedtest
```
# 如果想生成一张测速结果的图片链接分享给别人，可以加 --share 参数：
```bash
speedtest-cli --share
```
# 卸载 speedtest 命令行工具
```bash
sudo snap remove speedtest
```
